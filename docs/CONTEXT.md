# Project.BeenHere Domain

Project.BeenHere 保存陌生人在公开社交媒体或其他场景中发生的对话，使其成为长期可读、可认领、可修订的采访记录。

## 人与内容

**采访记录（Interview Record）**：
一次有明确被采访者、发生时间和来源的纯文本对话记录，可以来自抖音、其他社交媒体、本站直接采访或线下整理。

**被采访者（Participant）**：
采访记录中被提问、被了解的人；可以实名、化名或匿名呈现。

**采访消息（Interview Message）**：
采访记录中最小的有序纯文本片段，只属于 `interviewer`（采访者）或 `participant`（被采访者）。图片、停顿、系统信息和编辑说明不属于采访正文。

**记录编号（Record Number）**：
采访记录首次公开时获得的稳定公开标识，永不复用。

**公开版本（Published Edition）**：
采访记录一次公开内容的不可变快照；后续修改产生新版本，不静默覆盖。

## 账户与权利

**账户（Account）**：
以唯一已验证邮箱登录、在本站保存展示名与权限状态的自然人账户。

账户状态只有 `pending`（待验证）、`active`（正常）、`suspended`（停用）和 `deleted`（已删除）四种；状态不作为内容审核结论。

**记录主人（Record Owner）**：
可以修改、公开或软删除某条采访记录的账户，包括原上传者与获批认领者。

**馆长（Director）**：
可以管理所有账户与采访记录的超级管理员。

**认领申请（Claim Request）**：
登录账户以“我是被采访者”为由提交的申请，包含申请文本，由现有记录主人决定同意或拒绝。

**软删除（Soft Deletion）**：
使采访记录立即停止公开但保留版本、所有权与审计历史的可恢复删除。

账户删除与采访记录软删除是两件事。删除账户会匿名化账户资料并撤销登录能力，不自动删除已经公开的采访记录。

## 来源与录入

**来源记录（Source Record）**：
采访发生的平台、公开链接、外部标识与采集时间等出处信息。

**录入方式（Ingestion Method）**：
把已有文本转换成双角色采访消息的方式。当前默认流程是粘贴整段对话、识别消息、校对双方归属，再补充最少公开信息。

**来源证据（Source Evidence）**：
用于核验来源记录的受限原始材料，默认不公开。

## 实时状态

**在线访客（Online Visitor）**：
浏览器页面与本站实时在线房间保持 WebSocket 连接的访客。浏览器本地生成稳定随机标识，同一浏览器的多个标签页只计为一位；该标识不是账户身份，也不写入 D1。

**在线人数（Online Count）**：
实时在线房间内不同在线访客标识的数量。少于两人时界面不展示；它只表达当前连接状态，不代表可匹配、愿意受访或已经登录。

## 发现与治理

**漂流（Drift）**：
从公开采访记录中进行不按热度排序的随机相遇。

**更正请求（Correction Request）**：
公众请求更正、补充、隐私遮蔽或停止公开的治理信息，不直接修改采访记录。
