# 来过 Design System

## 1. 方向

视觉语言是“温柔的公共记录”：现代极简结构加轻微纸张触感。所有采访记录具有相同视觉重量；朱砂色只用于身份、状态和重要确认，蓝灰色用于可探索链接。

## 2. Token 架构

源码在 `apps/web/src/styles/tokens.css`，严格使用 primitive → semantic → component 三层。

- 纸张：`paper-0` 到 `paper-300`；亮色画布使用草纱纸米色 `#f0ebdc`，卡片使用较浅的 `#f7f3e8` 保持层级。
- 文字：主色 `ink-950`，次色 `ink-650`，保证正文对比度。
- 强调：`cinnabar-700` 用于印记和确认；`blueprint-800` 用于链接。
- 状态：错误颜色与表面颜色成对使用，不只依赖颜色传意。
- 间距：4px 基准，主要页面节奏为 40/64/80/96px。
- 圆角：2–8px；卡片默认 4px，避免过度圆润的消费产品感。
- 动效：150/240/420ms；尊重 `prefers-reduced-motion`。

纸张主题为默认。亮色画布使用 CSS 渐变叠加细颗粒、横向短纤维与纵向亮纤维，不加载位图或外部纹理资源；纹理只承担触感，不承载信息。夜间主题保持语义 Token 不变，并关闭纤维层、保留原有低对比颗粒。主题写入 `localStorage`，首次使用遵循系统偏好。

## 3. 字体

- 长文与标题：`Noto Serif SC` / 系统宋体，强调人的叙述。
- 导航与控件：`Inter` / 系统黑体，保证小字号清晰。
- 编号、状态与时间：`JetBrains Mono` / 系统等宽字体。

正文移动端不小于 16px，长文行高约 2；辅助信息不小于 12px。阅读列最大 720px。

## 4. 响应式布局

- Mobile 320–767px：单列，页面左右 20px；首页、漂流、记录、搜索、我的使用固定底部 tab，更多入口保留在顶部菜单。
- Tablet 768–1023px：双列卡片，12 列网格，页面左右 48px。
- Desktop ≥1024px：最大容器 1140px，采访记录列表三列，阅读区仍为 720px。
- 所有按钮、链接主触控区最小 44×44px；表单标签常驻，不用 placeholder 替代标签。

## 5. 核心组件

- `AppShell`：粘性主导航、实时在线人数、主题切换、账户入口、移动菜单和分组页脚；在线人数少于 2 或连接不可用时不占据界面空间。页脚使用品牌区与导航区两层网格，导航固定分为“了解来过 / 规则与权利 / 项目与账户”，移动端两列、平板及桌面三列，组内链接纵向排列且触控区不小于 44px。
- 账户入口使用站内 SPA 路由；受保护页面由 `RequireAccount` 校验 HttpOnly 会话，未登录时转到站内登录页并保留返回路径。
- `RecordCard`：编号、时间、被采访者、系统派生标题、摘要和阅读入口。
- `RecordMark`：公开状态的朱砂印记，不承担交互。
- `RecordForm`：可复用录入/编辑表单；默认粘贴、拖入或选择聊天截图并在浏览器中识别，纯文本粘贴折叠为回退入口，随后统一校对采访者/被采访者消息气泡。OCR 临时置信度不进入保存数据。
- `OcrImportPanel`：页面挂载期间可在任意焦点位置粘贴图片；支持 1–5 张预览、移除、进度、取消和错误回退。识别中禁用新增/移除，组件卸载时释放 Object URL 并终止活动 Worker。
- `AsyncState`：加载、错误和空状态，必须提供可读文本。

交互反馈就地出现；保存和公开是两个明确动作；删除必须说明原因；认领必须提交文本并由记录主人明确决定。

## 6. 无障碍与文案

语义 HTML 优先，键盘焦点使用 2px 朱砂轮廓。隐藏文件输入必须通过可见 label 的 `focus-within` 显示焦点；加载、进度、成功与失败使用可读文本和 live region，不依靠图标或颜色单独表达。界面官方名称始终是“采访记录”；人员分别称“被采访者”“记录主人”“馆长”“成员”。
