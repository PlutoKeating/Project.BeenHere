# 采访记录内容规范

## 可收录内容

收录陌生人随机采访陌生人所产生的真实对话。来源可以是抖音或其他公开社交媒体，也可以是线上直接对话、线下面对面采访及其他可说明来源的形式。

每条采访记录至少包含：被采访者公开显示名与身份呈现方式、采访时间、来源类型，以及至少一条采访者消息和一条被采访者消息。消息只保存纯文本；标题、摘要和公开路径由系统从对话派生。原始链接并非所有形式都必需，但有公开来源时应填写。

聊天截图 OCR 与纯文本解析都只是录入辅助，不改变内容标准。截图不会成为本站来源证据，也不会随采访记录保存；录入者必须核对识别文字、消息顺序和双方归属，并在公开前去除截图中未获授权的系统提示、账号信息或旁观者内容。

## 整理原则

- 保留原意、语气和对话顺序，不虚构，不替被采访者美化结论。
- 删除敏感信息时要在公开版本的变更说明中交代，不通过静默修改掩盖重要变化。
- 公开前确认展示名、身份方式和引用范围适合公开。
- 平台评论不自动成为采访记录的一部分。

## 维护与权利

上传者是初始记录主人。被采访者通过带文本的认领申请，经现有主人同意后成为共同主人。任何人都可提交事实更正、隐私、授权、补充或撤回请求；馆长可处理全站违规与账户风险。
