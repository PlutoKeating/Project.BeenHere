# 产品与体验原则

来过认真对待普通人的一次真实表达。它不按名气排序，不把被采访者变成可消费的人设，也不制造“值得被记录”的门槛。

核心动作是随机遇见：用户打开一条采访记录，遇到原本不会认识的人。对话视图是采访正文的唯一主视图，保留双方原话与顺序；记录信息视图说明来源、版本与变更。

界面应温柔、克制且有重量：纸张般的暖色背景、宋体长文、清楚的等宽编号、低饱和朱砂强调、大面积留白。移动端是主场，触控目标不少于 44px；桌面端只是增加空间，不改变内容秩序。

人的尊严高于内容完整性。匿名、隐私遮蔽、更正和停止公开都有明确入口；版本不可静默覆盖，但可以发布解释清楚的新版本或软删除。

自动化只用于减少录入劳动，不替用户决定事实。OCR 可以建议文字与双方归属，但必须把不确定性暴露给用户，允许交换、逐条修改、删除和回退到纯文本；截图默认留在浏览器，不能为了“更智能”而静默上传私人材料。

自动采访也必须暴露机器身份与能力边界。它可以用固定提纲和可审计规则帮助人开始表达，但不得冒充真人、伪造亲身经历或把模式匹配描述成理解。受访者可以跳过和结束，进行中内容默认不保存；敏感内容不深挖，现实安全永远先于记录完整性。
